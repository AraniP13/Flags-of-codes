# Flags-of-codes

We have run all these codes and generated the results using MAGMA.

# Codes
The codes section contains three algorithms to find:
1. The optimal flag effective length vector in lexicographic order of a given code by BestFlag_Algorithm.
2. The generalized weights of a given code by GenWeight_Algorithm.
3. Optimal shape in lexicographic order for the equivalence class of a given code by Shape_Algorithm.

# Results
This section contains the results generated by the above codes for certain parameters to compare the optimal flag effective length vector to the corresponding generalized weights.
On the filenames,
'q' denotes the size of our underlying field,
'm' denotes the degree of the extension field,
'n' denotes the length of the codewords,
'k' denotes the dimension of our code.
We have kept q=2 and m=4 i.e. degree 4 extension field over the binary field and varied the length of the code. Each of the results contain 1000 iterations of codes with these parameters generated randomly.
